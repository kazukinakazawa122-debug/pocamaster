# 01. 要件定義書（pocamaster）

- 作成日：2026-09-27
- 版：v0.1（たたき台）

---

## 1. 目的
IVE のフォトカード（ポカ）の収集状況を、コレクション（アルバム・イベント）単位とメンバー単位で見られるようにする。
コンプリート率と実績を目で見て確かめ、集める楽しさを高めることを目指す。

## 2. 利用者
- 本人のみ（1人で使う）。ログインやアカウントは不要。

## 3. 動作環境
| 項目 | 内容 |
|---|---|
| 端末 | iPhone |
| 形態 | **PWA（ホーム画面に追加して使う Web アプリ）**（※1） |
| 保存先 | 端末の中だけ（サーバーなし） |
| 通信 | オフラインでもすべての機能が使える |
| 開発 PC | Windows 11 |

※1 PWA を選んだ理由：Windows だけで開発でき、iPhone へのインストールにお金がかからないため。
注意：iPhone では「ホーム画面に追加」して使う必要がある。万が一データが消えたときに備え、バックアップ機能を必須とする。

## 4. 用語
| 用語 | 意味 |
|---|---|
| コレクション | ポカをまとめる単位。アルバムとイベントの両方を含む |
| コレクション種別 | アルバム（韓国盤）／アルバム（日本盤）／シーズングリーティング／ファンミ・ファンコン／ライブ・ツアー／ノンアルバム／ポップアップ／その他 |
| フォトカード | 1 種類のポカ（メンバー × 絵柄）。同じ絵柄を何枚持っていても 1 種類と数える |
| コンプリート率 | コレクション内の全種類のうち、所持している種類の割合 |

## 5. 管理対象
- メンバー：ユジン、ガウル、レイ、ウォニョン、リズ、イソの 6 人
- 範囲：デビュー（ELEVEN）から最新作まで。韓国盤と日本盤を**すべて**含む
- 1 つのコレクションに入るもの：本体封入、店舗特典、ラキドロ（**分けずに 1 つにまとめる**）
- アルバム以外：シーズングリーティング、ファンミ・ファンコン、ライブ・ツアー、ポップアップ
- ノンアルバム：アルバムに付かないカード（コラボ・音楽番組・雑誌・ファンクラブなど）。内容ごとにコレクションを分ける（例：`Pepsi × IVE 'BLUE & BLACK'`、`Magazine｜雑誌特典`）
- ツアーは 1 つのツアーを 1 つのコレクションにする（ソウル公演・日本公演などの違いは入手元で分ける）

## 6. 機能要件

### 6.1 コレクション管理
| ID | 機能 | 段階 |
|---|---|---|
| F-01 | コレクションを一覧で表示する（発売日順。種別で絞り込める） | 1 |
| F-02 | コレクションを追加・編集・削除する（名前、種別、発売日、カバー画像） | 1 |
| F-03 | 各コレクションのコンプリート率を一覧に表示する | 1 |

### 6.2 フォトカード管理
| ID | 機能 | 段階 |
|---|---|---|
| F-10 | コレクション内のカードを画像のグリッドで並べる（Bibliocards のような並べ方） | 1 |
| F-11 | メンバーごとに切り替えて表示する（全員／メンバー別タブ） | 1 |
| F-12 | 持っていないカードは暗く表示する | 1 |
| F-13 | カードをタップして状態を切り替える（下の「状態の定義」参照） | 1 |
| F-15 | カードを追加・編集・削除する（メンバー、入手元、バージョン、画像） | 1 |
| F-16 | 画像がないカードは仮カードで表示し、あとから画像を登録できる（仮カードの表示内容は下を参照） | 1 |
| F-17 | 画像を大きく表示する（タップで拡大） | 1 |
| F-18 | カードを状態で絞り込む（すべて／`未所持` だけ／`所持中` だけ） | 1 |
| F-19 | カードの枠をまとめて作る（メンバー × 入手元 × バージョン） | 1 |

**入手元とバージョン**
- 入手元：どこで手に入るカードか。例：`本体封入`、`Soundwave 特典`、`Apple Music ラキドロ`、`ポップアップ 来場特典`
- バージョン：同じ入手元で絵柄が複数あるときに区別する。例：`A ver.`、`ver.1`、`ver.2`（1 種類しかなければ空欄でよい）
- 表示するための情報なので、これでカードをグループ分けはしない（グループ分けはコレクション単位だけ）

**仮カードの表示内容**
```
┌──────────────┐
│ I've IVE             │ ← コレクション名
│ ウォニョン           │ ← メンバー名
│ Soundwave 特典       │ ← 入手元
│ ver.2                │ ← バージョン
└──────────────┘
```

**状態の定義**
- 状態は `未所持` / `所持中` の 2 つだけ。カードをタップするたびに切り替わる
- 枚数は記録しない
- コンプリート率には `所持中` を数える

### 6.3 進捗・実績
| ID | 機能 | 段階 |
|---|---|---|
| F-20 | コレクション別のコンプリート率 | 1 |
| F-21 | コレクション内のメンバー別コンプリート率 | 1 |
| F-22 | 全体まとめ画面（全体の所持種類数、コンプリート済みのコレクション数、メンバー別の全期間達成率） | 1（簡易）→ 2（充実） |
| F-23 | 実績バッジ（例：初コンプ、〇〇全種コンプ、100 種類達成） | 2 |
| F-24 | 収集履歴とグラフ（月ごとの増え方など）。状態を変えた日時を記録する | 2 |
| F-25 | 見せる用の画面（`未所持` のカードだけを、スクショしやすく並べる） | 2 |

### 6.4 データ
| ID | 機能 | 段階 |
|---|---|---|
| F-30 | 初期データ（全コレクションとカードの枠）を取り込む | 1 |
| F-31 | バックアップを書き出す（画像も含めて 1 ファイルにする） | 1 |
| F-32 | バックアップから戻す | 1 |

## 7. 非機能要件
- **見た目**：メンバーカラー（ユジン青、ガウルオレンジ、レイ黄、ウォニョンピンク、リズ緑、イソ赤）を使う。情報は K-Collect より少なくし、画像を大きく見せる
- **操作性**：片手で使えるようにする。状態はタップ 1 回で切り替えられる
- **性能**：数百〜千枚ほどのカードと画像を入れても、スクロールが重くならない
- **オフライン**：通信がなくてもすべての機能が使える

## 8. 対象外（作らないもの）
- ログイン・他の人との共有・取引マーケット
- 所持枚数、購入金額、入手日、保管場所などの細かい記録
- 公式画像の自動取得（画像は本人が登録する）
- 本体封入／店舗特典／ラキドロで分けた集計（入手元ラベルとして表示だけする）

## 9. 初期データの作り方
- アルバムとイベントの一覧、カードの種類、入手元とバージョンは Claude が調べて下書きを作る
- 下書きは誤りを含む可能性があるため、本人が確認してから取り込む
- 画像はすべて仮カード（コレクション名＋メンバー名＋入手元＋バージョン）の状態で始める
