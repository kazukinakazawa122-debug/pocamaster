# 06. デザインシステム（pocamaster）

- 作成日：2026-09-27
- 版：v0.1（たたき台）
- 参考：「25 Claude Design Tricks Guide」（RoboNuggets）のうち、このアプリに合うもの

見た目のルールをここにまとめる。実装するときは、必ずこのルールに従う。

---

## 1. 基本方針
- 主役はカード画像。画面の枠やボタンは控えめにする
- 色はメンバーカラーだけを使う。それ以外は白・灰色・黒
- iPhone の標準アプリに近い操作感にする（Apple の Human Interface Guidelines に従う）

## 2. 色

### 2.1 メンバーカラー
| メンバー | 塗り | 薄い背景（仮カード） | 文字として使う色 |
|---|---|---|---|
| ユジン | `#378ADD` | 塗りの 25% | `#185FA5` |
| ガウル | `#F08A3C` | 塗りの 25% | `#A8561A` |
| レイ | `#F2C230` | 塗りの 25% | `#9A7400` |
| ウォニョン | `#E85A9C` | 塗りの 25% | `#A8336A` |
| リズ | `#3FB56B` | 塗りの 25% | `#237A44` |
| イソ | `#E24B4A` | 塗りの 25% | `#A32D2D` |

- ユニットカードの縞は塗りの 33%（13% では所持・未所持の差がわかりにくかったため、2026-09-27 に変更）

- 白い背景の上に文字を置くときは「文字として使う色」を使う（明るい色のままだと読みにくいため）
- 塗りの上の文字は白。レイ（黄）だけは黒に近い灰色

### 2.2 土台の色
| 用途 | ライト | ダーク |
|---|---|---|
| 背景 | `#FFFFFF` | `#111113` |
| 面（カード・区切り） | `#F4F4F5` | `#1C1C1F` |
| 文字 | `#18181B` | `#F4F4F5` |
| 補助の文字 | `#71717A` | `#A1A1AA` |
| 区切り線 | `#E4E4E7` | `#2A2A2E` |
| 全員・全体の色 | `#3F3F46` | `#D4D4D8` |

- iPhone の設定に合わせて、ライトとダークを自動で切り替える

### 2.3 未所持の表示
- 画像に「白黒 80%＋明るさ 55%」をかける（見本と同じ）

## 3. 文字

| 用途 | 書体 | 大きさ | 太さ |
|---|---|---|---|
| 大きな数字（コンプ率） | Satoshi（Fontshare） | 34pt | 中太 |
| 画面タイトル | iPhone の標準書体（ヒラギノ角ゴ） | 20pt | 太字 |
| 本文 | 同上 | 17pt | 標準 |
| 補助・カード下のラベル | 同上 | 13pt | 標準 |
| いちばん小さい文字 | 同上 | 11pt | 標準 |

- 日本語は iPhone の標準書体を使う（日本語フォントはファイルが大きく、オフラインで持ち運ぶと重くなるため）
- 数字と英字だけ、Fontshare の Satoshi をアプリに同梱する（ITF Free Font License で無料で使える）。AI が作ったような「ありがちな見た目」を避けるため（ガイドの Tip 05）
- 11pt より小さい文字は使わない

## 4. 大きさ・間隔（Apple の Human Interface Guidelines より）
| 項目 | 値 |
|---|---|
| タップできるものの最小サイズ | 44 × 44 pt |
| 画面の左右の余白 | 16pt |
| 間隔の基本単位 | 4pt（4・8・12・16・24・32 を使う） |
| 角の丸み | カード 6pt、パネル 12pt、タブ（丸いボタン） 999pt |
| カードの縦横比 | 55 : 85（実物のポカに合わせる） |
| iPhone の上下の切り欠き | セーフエリアの内側に表示する |

- 「全員」タブで 6 枚並べたとき、1 枚の幅は 50pt 前後になる。44pt 以上なのでタップしやすさの基準は満たす

## 5. アイコン
- **Tabler Icons（アウトライン）だけ**を使う。自分でアイコンを描かない（ガイドの Tip 16）
- 形式は SVG（拡大してもぼやけず、色を変えられる。ガイドの Tip 17）
- 主なアイコン：ホーム `home`、コレクション `books`、実績 `trophy`、設定 `settings`、追加 `plus`、戻る `chevron-left`、コンプ済み `crown`

## 6. 動き
- 状態の切り替え：暗くなる・明るくなる変化を 0.15 秒で
- 「元に戻す」の表示：下から出て 3 秒で消える
- コンプリートしたとき：紙吹雪などのお祝いを出す（第 2 段階。軽いライブラリを使う）
- iPhone の「視差効果を減らす」がオンのときは、動きを止める

## 7. 言葉づかい
- 短く、1 つの画面で言うことは 1 つ
- ボタンは動詞で終わる：「追加する」ではなく「追加」、「保存」、「元に戻す」
- 空の画面は案内にする：「まだコレクションがありません」ではなく「最初のコレクションを追加」

## 8. 仕上げのチェック（実装のあと）
- ガイドの Tip 11「impeccable」のような観点で見直す：情報の優先順位、余白、文字、アクセシビリティ（読み上げ・コントラスト）、空の画面
