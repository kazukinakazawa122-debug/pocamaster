## 1. 色

### 1.1 メンバーカラー
| メンバー | 色 | 色コード（案） |
|---|---|---|
| ユジン | 青 | `#378ADD` |
| ガウル | オレンジ | `#F08A3C` |
| レイ | 黄 | `#F2C230`（文字に使うときは濃い黄 `#9A7400`） |
| ウォニョン | ピンク | `#E85A9C` |
| リズ | 緑 | `#3FB56B` |
| イソ | 赤 | `#E24B4A` |

### 1.2 使い方
- 土台は白（ダークモードでは黒に近い灰色）。カード画像が主役になるよう、背景に色を付けすぎない
- メンバーカラーは次の部分に使う
  - メンバー別タブ（選ばれているタブをその色で塗る）
  - 進捗バー・コンプ率の数字
  - 仮カードの枠と背景（薄い色）。ユニットカードは写っているメンバーの色を縞にする
- 「全員」タブや全体の進捗には、落ち着いた濃い灰色を使う

## 2. 画面の構成

画面の下のタブで 4 つの画面を切り替える。

```
[🏠 ホーム] [📚 コレクション] [📒 マイアルバム] [⚙️ 設定]
（2026-09-30：「実績」をやめて「マイアルバム」にした。本人の要望）
```

タブの画面（と S-11〜S-13）の上のバーの右上に 3 本線（メニュー）を置き、押すと右からサイドバーが出る（2026-10-01、本人の要望）。
タブに入らない機能はサイドバーから行く（S-11〜S-13）。機能が増えたらサイドバーに足す（src/components/SideMenu.tsx の ITEMS）

| ID | 画面 | 開き方 | 段階 |
|---|---|---|---|
| S-01 | ホーム | 下タブ | 1 |
| S-02 | コレクション一覧 | 下タブ | 1 |
| S-03 | コレクション詳細（カードのグリッド） | S-02 でコレクションをタップ | 1 |
| S-04 | カード拡大 | S-03 でカードを長押し | 1 |
| S-05 | カードの編集・追加 | S-04 の「編集」 / S-03 の「＋」 | 1 |
| S-06 | コレクションの追加・編集 | S-02 の「＋」 / S-03 の「編集」 | 1 |
| S-07 | カードの枠をまとめて作る | S-03 の「まとめて追加」 | 1 |
| S-08 | マイアルバム（一覧・中身・カードを選ぶ） | 下タブ | 1 |
| S-09 | 設定（バックアップ・取り込み） | 下タブ | 1 |
| S-10 | 見せる用の画面 | → S-12「求めているカード」として作った（2026-10-01） | — |
| S-11 | カードを探す | サイドバー | 1 |
| S-12 | 求めているカード（見せる用） | サイドバー | 1 |
| S-13 | 集めた記録（グラフ） | サイドバー | 1 |

## 3. 各画面

### S-01 ホーム
いちばん多い「家で眺める」ための画面。
```
┌────────────────────────┐
│ ⚠ 最後のバックアップから 14 日たちました │ ← 14 日たったときだけ出る
├────────────────────────┤
│  全体コンプ率                          │
│      62%   (412 / 664 種類)            │
│  ██████████████░░░░░░░░                │
│  コンプ済みコレクション  8 / 31         │
├────────────────────────┤
│  メンバー別                            │
│  ユジン    ██████████░░░  71%          │ ← 各メンバーの色のバー
│  ガウル    ████████░░░░░  58%          │
│  レイ      ...                         │
├────────────────────────┤
│  最近コンプしたコレクション            │
│  [カバー] [カバー] [カバー]  →         │
└────────────────────────┘
```

### S-02 コレクション一覧
```
┌────────────────────────┐
│ コレクション                     ＋    │
│ [すべて][韓国盤][日本盤][シーグリ]…    │ ← 種別で絞り込み（横にスクロール）
├────────────────────────┤
│ [カバー]  I've IVE                     │
│           2023-04-10  アルバム（韓国盤）│
│           ████████████░░  86%          │
├────────────────────────┤
│ [カバー]  2025 シーズングリーティング   │
│           ...                          │
└────────────────────────┘
```
- 新しいものが上。コンプ済みには王冠などの印を付ける

### S-03 コレクション詳細（カードのグリッド）
```
┌────────────────────────┐
│ ← I've IVE                   編集  ⋯  │
│ 86%  ████████████░░  (43 / 50)         │
│ [全員][ユジン][ガウル][レイ][ウォニョン][リズ][イソ] │ ← 色付きタブ
│ [すべて][未所持][所持中]               │ ← 状態で絞り込み
│ メンバー別 72%                          │ ← メンバータブを選んだときだけ出る
```

**「全員」タブのとき：入手元＋バージョンごとの段に、6 人を横に並べる**
```
├────────────────────────┤
│ 本体封入 A ver.                  5/6  │ ← 段の左上に「何の特典の何のカードか」
│ [ユ][ガ][レ][ウ][リ][イ]              │ ← 6 人を横 1 列（メンバー順）
│ Soundwave 特典 ver.1             6/6  │
│ [ユ][ガ][レ][ウ][リ][イ]              │
│ ユニット特典                     0/1  │
│ [ユ・ウ]                              │ ← ユニットカードは人数分より少なく並ぶ
└────────────────────────┘
```
- 段の見出し：入手元＋バージョン。右端にその段の所持数を出す
- カードの下にはメンバー名だけを出す（入手元は見出しにあるため）
- 段の並び順：コレクションに登録した順

**メンバー別タブのとき：横 3 枚のグリッド**
```
├────────────────────────┤
│ ┌──┐ ┌──┐ ┌──┐                   │
│ │  │ │▓▓│ │  │  ← 横 3 枚              │
│ └──┘ └──┘ └──┘   ▓ = 未所持（暗い）  │
│ 本体封入  Soundwave  Apple Music       │ ← カードの下に入手元＋バージョン
│ A ver.    ver.1      ラキドロ          │
└────────────────────────┘
```

**メンバーのタブ**
- コレクションのカードに出てくるメンバーだけをタブにする（例：Pepsi はウォニョンとイソだけ）
- 1 人しか出てこないコレクション（個人）は「全員」タブを出さず、入手元ごとの段に横 3 枚で並べる

**共通**
- **タップ**：`未所持` ⇔ `所持中` を切り替える
- **長押し**：カード拡大（S-04）を開く
- 未所持のカードは暗くする（画像を暗く＋灰色がかった色にする）
- 切り替えたときに、画面の下へ「元に戻す」ボタンを数秒だけ出す
- **まとめて切り替える**（2026-10-01）：「すべて・未所持・所持中」の右端の「選ぶ」を押すと、カードを押して選べる（選んだカードは黒い枠と印）。
  下のタブの代わりに出るバーで「所持中にする」「未所持にする」「譲（印を付ける・外す）」をまとめて行う（「元に戻す」付き）。「見えているのを全部」で、いま見えているカードを全部選ぶ
- 「譲」の印を付けたカードには、左上に小さな「譲」の札を出す

### S-04 カード拡大
- 画像（または仮カード）を画面いっぱいに表示する
- 表示：コレクション名、メンバー名、入手元、バージョン、状態
- ボタン：状態の切り替え、お気に入り（ハート）、譲（印を付ける・外す。持っていないカードに付けたら「所持中」にもする）、画像を登録・変更、編集、削除

### S-05 カードの編集・追加
- 入力：メンバー（複数選べる）、入手元、バージョン、画像
- 入手元はそのコレクションで使ったことのあるものから選べる（入力の手間を減らすため）

### S-06 コレクションの追加・編集
- 入力：名前、種別、発売日・開催日、カバー画像

### S-07 カードの枠をまとめて作る
```
入手元   [Soundwave 特典      ]
バージョン [ver.1, ver.2, ver.3 ]  ← カンマ区切り
メンバー [✓ユジン ✓ガウル ✓レイ ✓ウォニョン ✓リズ ✓イソ]
            → 6 人 × 3 バージョン = 18 枚を作成します  [作成]
```

### S-08 マイアルバム（2026-09-30、実績の代わり）
- 自分で好きなポカを並べるバインダー。アルバムはいくつでも作れる（名前は変えられる）
- 1 ページは 3×3 のポケット。「ページを追加」で増やし、左右にスワイプ（または ‹ › ボタン）でめくる
- 空いたポケットを押す → カードを選ぶ画面（入れられるのは所持中のカードだけ。本人の要望。コレクション・メンバーで絞る）。あとで未所持に戻したカードは暗く表示
- カードの入ったポケットを押す → 「ほかのカードに入れ替える」「アルバムから外す」
- 一覧では 1 ページ目を小さく出す。バックアップに入る。カードを削除するとアルバムからも外れる

### S-09 設定
- バックアップを書き出す（最後に書き出した日を表示）
- バックアップから戻す
- 初期データ・追加データの取り込み（CSV）

### S-10 見せる用の画面（第 2 段階）
- 選んだコレクションの `未所持` カードだけを、余計なボタンなしで並べる → S-12 として作った

### S-11 カードを探す（2026-10-01）
- 言葉を入れると、全部のコレクションのカードから探す。調べる所：コレクション名・種別・発売年・入手元・バージョン・メンバー名
- 空白で区切ると「両方を含む」。全角・半角、大文字・小文字、カタカナ・ひらがなの違いは無視。「ポラ」で POLA、「シーグリ」でシーズングリーティングも見つかる
- メンバー・状態（すべて／未所持／所持中）で絞れる。結果はコレクションごと（新しい順）。タップで状態を切り替え、長押しで拡大
- 何も入れていないときは、押すと入る言葉の例（withmuu・Soundwave・ポラ など）を出す

### S-12 求・譲の一覧（2026-10-01、F-25。はじめは「求めているカード」）
- 上で「求めているカード」と「譲れるカード」を切り替える。譲れるカード＝「譲」の印を付けた、持っているカード（押すと拡大を開く。押しただけで未所持にならないように）
- 「この一覧を画像にする」→「画像を保存・共有する」（2 回押す。iPhone の共有シートは押した直後でないと開けないため）。横 1080px、明るい色、見出し・コレクション名・カード（名前を出すなら名前も）。
  高さ 7,600px を超えたら何枚かに分ける。300 枚を超えたら絞ってもらう（src/lib/listImage.ts）
- `未所持` のカードだけを並べる。スクショして交換・譲渡で見せる用なので、持っていないカードも暗くしない
- 絞り込み：メンバー・コレクション・お気に入りだけ・画像のあるカードだけ（はじめは ON）・名前を出す・横の枚数（3〜6）。選んだ絞り込みは次も同じ
- 上に「求 ＋ メンバー名・コレクション名・枚数」の見出し。右上のボタンで絞り込みを隠せる（スクショ用）
- カードを押すと「所持中」になって一覧から消える（「元に戻す」付き）

### S-13 集めた記録（2026-10-01、F-24）
- 状態を変えた記録（statusHistory）から、月ごとに「所持中」が何枚増えたかを 12 か月分の棒グラフにする。「未所持」に戻した分は引く（減った月は線より下）
- 大きな数字は選んだ月（はじめは今月）。棒か下の表の行を押すと、その月になる。メンバーで絞れる
- 同じ内容を表（月ごとの枚数）でも出す。その下に最近「所持中」にしたカード 30 枚
