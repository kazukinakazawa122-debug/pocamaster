# 05. 技術選定（pocamaster）

- 作成日：2026-09-27
- 版：v1.0（決定）

## 1. 使う技術
| 役割 | 使うもの | 理由 |
|---|---|---|
| 画面づくり | React + TypeScript | 利用者が多く、情報が見つけやすい |
| 開発の土台 | Vite | 変更をすぐ確認できる |
| データの保存 | IndexedDB（Dexie） | iPhone の中にデータと画像を保存できる |
| オフライン対応 | PWA（vite-plugin-pwa） | ホーム画面に追加でき、通信なしで動く |
| バックアップ | JSZip | データと画像を 1 つの .zip ファイルにまとめる |
| アイコン | Tabler Icons（SVG、MIT ライセンス） | 1 つのスタイルでそろったアイコン集（06 参照） |
| 公開場所 | GitHub Pages（無料） | iPhone から https で開くための置き場所 |

## 3. 公開とデータの関係
- GitHub Pages に置くのは**アプリのプログラムだけ**
- カードの状態・画像・履歴は iPhone の中（IndexedDB）にだけ保存し、外に送らない
- 無料で GitHub Pages を使うにはリポジトリを**公開（public）**にする必要がある。プログラムと初期データ（アルバムとカードの一覧）は誰でも見られる状態になる。個人の収集記録は含まれない

## 4. iPhone で使うときの注意
- Safari で開き、「共有」→「ホーム画面に追加」で使う
- ホーム画面から開いたアプリのデータは、Safari のタブで開いたときとは別に保存される。必ずホーム画面から使う
