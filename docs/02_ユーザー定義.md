# 02. ユーザー定義・利用シーン（pocamaster）

- 作成日：2026-09-27
- 版：v0.1

---

## 1. ユーザー像
| 項目 | 内容 |
|---|---|
| 利用者 | 本人のみ |
| 集め方 | IVE 全メンバーのカードを集める（推しメンはいるが、アプリで特別扱いはしない） |
| 端末 | iPhone |
| 集める範囲 | アルバム（韓国盤・日本盤）、シーズングリーティング、ファンミ・ファンコン、ライブ・ツアー、ポップアップ |
| 追加の頻度 | 新しいアルバムやイベントが出るたびに、コレクションを追加する |

## 2. 利用シーン

| # | シーン | 場所 | やりたいこと | 大事なこと |
|---|---|---|---|---|
| S1 | **家でゆっくり眺める**（いちばん多い） | 家 | コンプ率・実績を見て楽しむ | 見た目の楽しさ。画像を大きく、達成感が伝わる |
| S2 | 開封直後に登録 | 家 | 出たカードを `所持中` にする | 探す手間が少ない。タップ数が少ない |
| S3 | 取引の相談中 | どこでも | 持っているかをすぐ確認する | 開いてすぐ目的のカードにたどり着ける |
| S4 | イベント・ポップアップ会場 | 会場（電波が弱いこともある） | 足りないカードを確認する | オフラインで動く。未所持がひと目でわかる |
| S5 | 足りないカードを人に見せる | どこでも | 取引相手に未所持のカードを見せる・スクショを送る | 余計な情報がなく、スクショ 1 枚で伝わる |
| S6 | 新しいカムバ・イベントの追加 | 家 | コレクションとカードの枠を登録する | まとめて入力できる |

## 3. 設計への反映
| シーン | 反映すること |
|---|---|
| S1 | ホーム画面は「眺めて楽しい」ことを最優先にする（コンプ率、メンバー別の進捗、最近コンプしたコレクション） |
| S2 | カードをタップするだけで `未所持` ⇔ `所持中` が切り替わる。連続で登録しやすい |
| S3・S4 | 状態で絞り込む（`未所持` だけ など） |
| S4 | オフライン対応（要件定義 7 章のとおり） |
| S5 | **見せる用の画面**：選んだコレクションの `未所持` のカードだけを並べた、スクショしやすい画面 |
| S6 | カードの枠をまとめて作れるようにする（例：6 人 × ver.1〜3 を一度に作る） |

## 4. 要件定義への追加（2026-09-27 決定・01 に反映済み）

|---|---|---|
