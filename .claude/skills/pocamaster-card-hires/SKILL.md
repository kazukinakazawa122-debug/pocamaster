# pocamaster：実物の写真でカードの画質を上げる

本人は日本語で、はじめてアプリを作っている人。説明は短く、丁寧な言い方（〜しました）で。進め方の細かい記録は docs/00_進捗メモ.md の 57.〜61.（最初に「次のセッションへの引き継ぎ」を読む）。

## 全体の流れ

1. どこを探すか決める → 2. Chrome で候補を集める（保存はしない）→ 3. 候補を一覧にして本人の了承をとる → 4. 保存 →
5. 照らし合わせ（裏で）→ 6. Claude が見比べ・透かし・端を確かめる → 7. 差し替え・ZIP・一覧・メモ・コミット → 8. 本人に見比べの JPEG を送る

長い作業なので、最初にチェックリストを出し、終わったものから消す（本人の決まり）。

## 1. どこを探すか

- 粗い・ぼかし・画像なしの数は `python tools/crop/review_todo.py`（数を出す。約 2 分）。コレクション・お店ごとの内訳は全部入りの ZIP から数える。
- 本人が「多いのから」と言ったら、粗いカードのいちばん多いコレクションから。そのコレクションの中では、残っている数の多いお店（source）から。

## 2. 探し方（Claude in Chrome）

- メルカリ：`https://jp.mercari.com/search?keyword=IVE%20<コレクション>%20<お店の名前>%20トレカ`。結果のページで下へスクロールし、`a[href*="/item/"]` から「出品番号 | 題名」を集める（題名にコレクション名があるものだけ）。
  - お店の名前は、日本語の呼び方でも探す（ミューコリ＝Music Korea、メイクスター＝Makestar、サウェ＝Soundwave、ケタポ＝Ktown4U、ソニミュ など）。
  - **カード 1 枚の出品**がいちばん良い（写真の中でカードが大きい。高さ 600〜1,000px）。6 枚コンプの写真は 1 枚あたり 400px ほど。メンバー別のまとめ売り（20 枚以上が 1 枚の写真）は小さいので外す。
  - 写真は `https://static.mercdn.net/item/detail/orig/photos/<出品番号>_1.jpg`（1 枚目＝表）。
- X：`https://x.com/search?q=<韓国語の語句>&f=media`（例「펩시 아이브 포카 since:2025-03-01」）。元の大きさは `pbs.twimg.com/media/<id>?format=jpg&name=orig`。告知画像はぼかし入り・重なりが多い。
- 見るだけ。ログイン・購入・いいね・コメントはしない。使い終わったタブは閉じる。

## 3. 保存の了承（毎回必ず）

保存（ダウンロード）は、そのたびに本人の了承が要る（了承は一覧ごと。前の了承を次の一覧に広げない）。お店ごとの件数の表・保存元（static.mercdn.net など）・保存先・おおよその大きさを見せて聞く。本人が「進めて」「保存してよい」と言ったら、その一覧の分だけ保存する。了承待ちの候補は、出品番号を進捗メモに書いておく。

保存先：`pocamaster-images/新しい資料 <日付>/<わかる名前>/` に `<お店の名前>_<出品番号>.jpg`（`curl -s -f -m 30`）。画像は Git に入れない。

## 4〜7. 道具：tools/crop/mercari_hires.py

`<名前>` は日付と通し番号（例 `20261024a`）。あとの回ほど後ろの名前にする（job は名前の順に読まれ、同じ枠ならあとの画像が勝つ）。

```
python tools/crop/mercari_hires.py find   <名前> "新しい資料 <日付>/<フォルダ>" [コレクション]   # 裏で（run_in_background）。1 件 10 秒ほど
python tools/crop/mercari_hires.py sheet  <名前>   # 候補（0.68 以上・1.15 倍以上、枠ごとに 1 つ）の新旧の並び → pocamaster-images/メルカリ見比べ/_作業/
```

**見比べ（Claude）**：候補の画像を読み、新旧が**同じ写真**かを 1 組ずつ決める。顔でメンバーを決めない（同じ写真かどうかだけ）。外すもの：
- ちがうカード、カードの上に出品者の文字・シール・バーコード・「@ID」・「2枚」などがかかるもの
- 前の画像がぼかしで決めきれないものは入れてよいが、本人の確認に回す

結果を `tools/crop/review/hires/<名前>.json` の `"ok": [番号…]` に書き、理由を `"note"` に残す。

```
python tools/crop/mercari_hires.py big <名前>   # OK のものを高さ 520px で並べる
```

**透かしと端（Claude）**：大きい画像を全部読む。メルカリの写真には、カード全体に**出品者の薄い透かし**（「メルカリ mxl」「メルカリ @…」のくり返し）が入っているものがあり、小さい画像では見えない。怪しいものは上半分を 2 倍にして確かめ、あれば ok から外す。端に背景・となりのカード・スリーブが残っていたら `"trim": {"番号": [左, 上, 右, 下]}`（カードの幅・高さに対する割合、0.02〜0.05 ほど）で内側に寄せ、もう一度 big で確かめる。

```
python tools/crop/mercari_hires.py apply <名前>
python tools/crop/merge.py && python tools/crop/make_diff.py
python tools/crop/make_diff_since.py <iPhone が取り込み済みの番号>   # iPhone 用に 1 つにまとめる（取り込み済みの番号は進捗メモの「状態」）
```

- ZIP を testzip で検査（全部入りとまとめた差分）。`python tools/crop/review_todo.py` で要対応カード一覧を作り直す。
- merge の結果で、job の枚数より差し替えが少ないときは、前の job と同じ枠で負けている。どの枠かを調べる（名前の順の問題）。
- 進捗メモ：「状態」の行（全部入りの番号・iPhone に入れる ZIP）と、新しい番号の項目（何をした・外した理由・次の候補）を書く。道具・設定・job（tools/crop/out/…_zz_<名前>.json）・メモをコミット。**push は本人が「push して」と言ったときだけ。**

## 8. 本人への報告

```
python tools/crop/mercari_hires.py review <名前>   # pocamaster-images/メルカリ見比べ/<名前>_N.jpg（左＝新しい写真、右＝前の画像）
```

- **SendUserFile で JPEG を送る**（display: render）。本人はスマホで見ることが多く、HTML は開けなかった。
- **本人に見てほしい・使ってほしいファイルは、場所を書くだけでなく毎回 SendUserFile で送る**（本人「毎回そのリンクを送ってほしい。見れません」2026-10-23）。iPhone に入れる差分 ZIP も送る（display: attach）。
- 「ちがうものがあれば番号を教えてください」と書く。ちがうと言われたら ok から外して apply からやり直す（前の画像に戻る）。
- 報告は短く：差し替えた枚数、粗いカードの数の変化（前 → 後）、外したものと理由、iPhone に入れる ZIP、本人に聞くこと、次の候補。

## 画像のルール（本人の決まり）

- カードの上に人の ID・透かしがある画像は使わない。お店の印（SuperStar STORE の斜めの文字、K·MONSTAR のロゴ、中国のお店の名前など、カードやスリーブに印刷されたもの）は使ってよい。
- 明るさは上げない（白っぽくなる）。彩度は上げてよいが、今の流れでは補正しない。
- 今の画像より 1.15 倍以上大きいときだけ差し替える。
